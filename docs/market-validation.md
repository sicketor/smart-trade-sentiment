## Caveats

| caveat | effect |
|---|---|
| The norm (mu, sd) and the grade cuts were fitted on the same corpus window | rho is unaffected (a fixed monotone map per group); the grade cut points are in-sample |
| Feeds keep only their latest items, so older days are thinner (survivorship) | early days carry fewer, possibly non-random items |
| The day CI rests on only 7 day-clusters | indicative only |
| h = 3 has only 4 start days, with overlapping windows | h = 3 results are anecdotal |
